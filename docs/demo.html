Cancel rule

A turn cancellation is blocked unless the remaining two-pup capacity covers projected demand in both directions. A location-level saving never outranks return-leg freight or downstream service.

Explain margin one shipment at a time.

Revenue is matched with P&D, dock handling and each linehaul leg. Turn cost is allocated by cube share, so freight that creates directional imbalance carries its paired empty-return burden.

COST-TO-SERVE NARRATOR
This shipment lost $119.26. Its $21.95 revenue did not cover the $80 pickup-and-delivery floor. Routing via SGF added four dock touches ($56) and two doubles-turn allocations ($5.21). The first action is pricing or minimum-charge review—not a cheaper-mile claim the network cannot deliver.

The supplied v1 sample ledger uses cube share. Production should attribute each leg using the binding cube/weight driver plus marginal trailer creation, then reconcile allocations to the full paired turn. This avoids understating dense, weight-constrained freight.

A daily load-planning model planners can audit.

The production formulation is a mixed-integer program. This prototype uses a transparent greedy deviation search from the standard-path start so every move remains traceable.

Output

Doors, turns, pup-slot assignments, costed deviations, residual capacity, network checks and exceptions.
